# Åland Baits UF

Övningshemsida för Åland Baits UF – handgjorda fiskedrag från Åland.
Byggd med vanlig HTML, CSS och JavaScript.

## Byta bilder
Alla bilder ligger i `bilder/`. Ersätt en fil med en ny som har exakt samma namn.
Saknas en bild visas en grå platshållare med filnamnet.

Bilderna är tillfälliga exempelbilder och föreställer inte företagets egna beten.
